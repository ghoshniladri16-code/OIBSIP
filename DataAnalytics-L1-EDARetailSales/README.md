# 📊 Task 1: Exploratory Data Analysis on Retail Sales Data

## 📌 Objective
To perform a comprehensive Exploratory Data Analysis (EDA) on a retail sales dataset to uncover seasonal trends, demographic buying patterns, and actionable business insights.

## 🛠️ Tech Stack
* Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook

## 🔍 Key Findings & Highlights
* Cleaned transactional records and validated datatypes.
* Extracted temporal attributes (Month, Day, Revenue).
* Visualized monthly sales volume and identified top product categories.
* Generated actionable insights for inventory and marketing strategies.
